Na prática

Você manda o link de uma skill do GitHub. Sem instalar nada, o agente lê os arquivos e monta uma página com o veredito, os riscos, o gasto estimado e um mapa de como ela funciona. Assim, você decide antes de baixar.

Para quem é

  • Serve para: quem usa agentes de IA e quer entender uma skill antes de instalar.
  • Não serve para: quem precisa de garantia formal de segurança.
  • Não faz: não executa a skill analisada, então não mede o uso real nem prova que ela é segura.
A linha "não serve para" é leitura minha a partir dos arquivos.
Estimativa de gasto para carregar: cerca de 115 tokens em toda sessão, 3,1 mil de instruções ao acionar e mais 11 mil se ler o exemplo. No total de 14 mil: 0,14% da semana, cerca de US$ 0,03 no plano de US$ 100 por mês e R$ 0,18 no de R$ 550 por mês. Premissa sem fonte oficial: 10 milhões de tokens por semana, com o mês dividido em cerca de 4,3 semanas. O trabalho de cada análise não foi medido e costuma custar bem mais, porque depende do tamanho do repositório. A auditoria opcional custou cerca de US$ 3,40 em preço de API por rodada no modelo mais capaz, em uma sessão medida.

Antes de instalar

Avaliação feita pela própria skill, portanto não independente. O repositório passou por uma auditoria de vazamento de dados antes de ser publicado. Leia o SKILL.md você também.

O que ela roda

Um único script, scripts/custo.py, que faz a conta do gasto. As instruções mandam o agente usar gh e abrir um navegador para testar a página.

Lido no código. scripts/custo.py; SKILL.md.

O que ela toca

Consulta o GitHub com o seu login do gh, cria a página e pode publicá-la, se houver ferramenta para isso. O script só grava em scripts/planos.json, e só com o comando calibrar. Pode copiar o repositório analisado para uma pasta temporária.

Lido no código. scripts/custo.py; SKILL.md, "Skill de terceiro" e "Antes de entregar".

O que sai para a internet

Leituras no GitHub. As páginas carregam fontes do Google e trazem um link para o Instagram do autor no rodapé. A página pode guardar no navegador a paleta escolhida.

Lido no código. exemplo/mapa-webapp-testing.html.

De que depende

Python 3 e GitHub CLI. Um agente que siga as instruções, um navegador para os testes e, para a auditoria, suporte a subagentes.

Lido no código. README.md; SKILL.md.

Limites conhecidos

A opção de colar uma promessa ainda não teve teste real. A instalação a partir do GitHub em máquina limpa também não foi testada. O gasto mostrado é estimativa.
